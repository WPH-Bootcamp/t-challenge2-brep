# Challenge 2 - Build an Educational Article Page with HTML

## Description

In this assignment, you’ll create a **simple article webpage** using **pure HTML**.  
The goal is to demonstrate your understanding of **semantic elements**, **text structure**, and **basic accessibility**.

You only need to work with **one file**:

    root/
     └── index.html

This assignment will help assess your ability to:

- Structure content using semantic HTML tags (`<article>`, `<section>`, `<header>`, `<footer>`, etc.)
- Embed text, images, tables, and forms in a logical flow
- Maintain readability, accessibility, and clean formatting

---

## Assignment Objectives

Your `index.html` must include the following sections:

1. **Page Setup**

   - HTML5 structure with proper `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.
   - Title (`<title>`) and meta tags for charset and viewport.

2. **Header Section**

   - Use `<header>` to include the article title (`<h1>`), author name, and publication date.
   - Add a short description or tagline using a `<p>` tag.

3. **Table of Contents**

   - Add a list (`<ul>` or `<nav>`) containing internal links to article sections (using `id` and `href="#section-id"`).

4. **Main Article Content**

   - Use `<main>` and `<article>` to structure your writing.
   - Divide content into at least **three sections** using `<section>` and subheadings (`<h2>`, `<h3>`).
   - Include:
     - Paragraphs with meaningful text.
     - At least **one image** with descriptive `alt` text.
     - A **list** (`<ul>` or `<ol>`) for supporting points.
     - A **quote** (`<blockquote>`) or **code snippet** (`<code>`) if relevant.

5. **Table**

   - Create a small table summarizing data, comparisons, or statistics.
   - Include `<thead>`, `<tbody>`, and `<caption>`.

6. **Feedback Form**

   - Add a simple feedback form at the end of the article using `<form>`.
   - Include:
     - Text input (Name)
     - Email input
     - Dropdown/select for rating (e.g., “Very Helpful”, “Neutral”, “Needs Improvement”)
     - Textarea for comments
     - Submit button

7. **Footer**
   - Use `<footer>` to include the author’s contact info, copyright, or reference links.

## Optional (Bonus)

To make your article more professional:

- Include an embedded video (e.g., YouTube iframe) or audio relevant to the topic.
- Add navigation (`<nav>`) to jump between sections.
- Include social media links.
- Create a design wireframe in **Figma** and export one asset to include in the page.
